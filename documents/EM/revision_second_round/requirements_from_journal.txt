1) Manuscript Source Files

We cannot accommodate PDF manuscript files for production purposes. Please upload the LaTex files using the 'LaTeX Source files' file-type and a pdf file of your manuscript using the "Revised Manuscript (clean version)" file-type. If you did not use LaTex to create your manuscript, the manuscript should be uploaded as a Word document. Refer to the Guide for Authors for additional information: https://www.elsevier.com/journals/economic-modelling/0264-9993/guide-for-authors


2) Figure Source Files

Please make sure that artwork files are in an acceptable format (TIFF, EPS or MS Office files) and with the correct resolution. Figures and tables may be embedded within the source file for the submission if they are of sufficient visual quality. For any figure that cannot be embedded within the source file (such as *.PSD, Photoshop files), the original figure needs to be uploaded separately. Refer to the Artwork Instructions for additional information at http://www.elsevier.com/artworkinstructions

3) Link to Replication Folder

Please use the following checklist to ensure your replication package is complete.

README CHECKLIST

## Title and Overview
- The README should include the paper title and the authors' names.
- The README should include a brief overview of the replication package.

## Data Information

- The README should indicate the public availability status of the data.
- The README should provide detailed information on each data source.

## Instructions to Replicators

- The README should list all required dependencies (e.g., software, packages, and libraries).
- The README should include step-by-step replication instructions.

## List of Tables and Programs

- The README should include a list of all tables and figures, along with the scripts that generate them.
- The README should include a summary table listing all tables and figures, along with the corresponding programs and output files.


DATA SHARING

## Raw Data. Primary data collected by the author and secondary data not otherwise available must be included in the replication package unless the exceptions for non-public data apply.

## Analysis Data. Analysis data should be provided as part of the replication package unless the exceptions for non-public data apply.

## Non-Public Data. If raw or analysis data cannot be shared publicly, authors must document the restriction in the README and include a pseudo-data set that illustrates the format of the files read by the code (i.e., synthetic data that preserve original means, standard deviations, and number of observations, with variable names and identifiers kept identical to the original data).

CODE SHARING

## Data Management Code. The Package must include all programs required to clean, merge, and transform raw data into analysis data.

## Analysis Code. The Package must include all programs that produce the computational results reported in the submission.

## Format. Code must be provided in a well-commented, executable source format that can be interpreted or compiled by the appropriate software.
